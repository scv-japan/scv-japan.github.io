# SCV@Japan

このリポジトリは多変数関数論の研究集会の記録を公開する GitHub Pages サイトです。

| フォルダ | 内容 |
| --- | --- |
| [`hayama/meetings/`](hayama/meetings/) | 葉山・京都シンポジウムの開催記録。開催年ごとに案内、プログラム、配布資料を配置 |
| [`hayama/archive/`](hayama/archive/) | 葉山シンポジウムの旧記録。開催年別の資料は `years/`、写真は `photos/` |
| [`hayama/assets/`](hayama/assets/) | 葉山の記録ページで共用するスタイルと画像 |
| [`hayama/site-export/`](hayama/site-export/) | 旧 Google Sites のシステムページとフィード |
| [`summersemi/`](summersemi/) | 夏・冬セミナーの開催記録 |
| [`oka100/`](oka100/) | 岡潔生誕百年記念会議の資料、写真、動画 |
| [`conference/`](conference/) | その他の研究集会と関連資料 |
| [`_maintenance/drafts/`](_maintenance/drafts/) | 公開用ページの整理前の作業ファイル |

公開の入口は [日本語トップ](index-j.html) と [英語トップ](index.html) です。ルート直下の開催年ファイルや旧ディレクトリに残る転送ページは、既存のブックマーク用です。本文の編集には転送先のファイルを使います。

## 2026年11月25日の更新

[葉山シンポジウム写真集](hayama/archive/photos/)に、1999・2002・2003・2004・2005年のリマスター済み写真393枚を掲載しました。3列のサムネイルは広い画面で従来の約2倍の幅で表示し、全年度をページ全体の縦スクロールで閲覧できます。拡大表示は画面幅を上限にサムネイルの2倍の幅とし、写真の縦横比とDriveの原版リンクを維持しています。
